% === 自动分页：让 section, subsection, subsubsection 按层级智能分页 ===
% 规则：
% - 第一个标题不分页（避免目录后空白）
% - 同一级标题之间分页（例如两个 section 之间分页）
% - 从高级到低级（section -> subsection -> subsubsection）不分页（因为上级已分页）
% - 从低级回到高级或同级（subsubsection -> subsection 或 subsubsection -> section 或 subsection -> section）会分页

\newcounter{lastlevel}
\setcounter{lastlevel}{0}

\newcommand{\maybePageBreak}[1]{%
  \ifnum \value{lastlevel}=0
    % 第一个标题，不分页
  \else
    \ifnum #1 > \value{lastlevel}
      % 标题层级加深（从高级到低级），不分页
    \else
      % 同级或降级，分页
      \clearpage
    \fi
  \fi
  \setcounter{lastlevel}{#1}
}

\let\oldsection\section
\renewcommand{\section}{%
  \maybePageBreak{1}%
  \oldsection
}

\let\oldsubsection\subsection
\renewcommand{\subsection}{%
  \maybePageBreak{2}%
  \oldsubsection
}

\let\oldsubsubsection\subsubsection
\renewcommand{\subsubsection}{%
  \maybePageBreak{3}%
  \oldsubsubsection
}

\section*{阅读须知}
\addcontentsline{toc}{section}{阅读须知}

\begin{spacing}{1.2}
\setlength{\parskip}{0.8\baselineskip}

小心地分析清零带来的影响，宁愿多清不能漏网，而且这种问题一般很难检查和拍出来。

善用宏可以有效避免重名问题。

\subsection*{应查找的内容}
\begin{itemize}
    \item 整数溢出、数组边界
    \item 特殊情况（n=1? A=0?）
    \item 做一些事情，而不是什么都不做，保持条理性
    \item 写点什么东西
    \item 不要拘泥于一种方法
\end{itemize}

如果队伍中存在 2 位可以独立读题的同学，建议一人正序从第一题开始看，一人逆序从最后一题开始看，看不懂英文的同学可以帮助团队先打开编译器、敲好头文件、做好准备工作。前期可以同时开两题，水题和签到题的 AC 速度就是优势，需要尽快建立。

某题出现很多人提交错误，但是看起来又比较简单的题，一定要再仔细想一想此题是否有坑。

一道题过的人数就说明了一道题的难易程度，如果一道你认为思维复杂度不高的题过的人数很少那一定是你想简单了。

由于本科组的同学过题速度比较快，可以选择跟本科组同学的榜单（优先选择本科组同学过题较多的题目）。切忌不要跟中学生的榜单，例如学军中学、杭州二中、镇海中学等，他们的学习方法与大学生不一样，他们会的我们不一定会。

如果其他专科组队伍短时间内过的题，而自己队伍想出来的解法实现较困难或者写代码的时间较长，则一定是没有考虑到更加方便的正解（往往这类题目涉及到数学、思维），请再仔细想一想更加简单的写法。

比赛封榜后，如果全场过题数 >= 200 的题目，一定是简单题， >= 100 的题目，一定是可以做的题目。

封榜这一个小时，就是逆风翻盘的最好时机，这最后一个小时内罚时不重要了。

提交结果是 TLE 的话，考虑是否使用了容器操作。例如 vector, map 等，如果使用 map 且没有排序需求的情况下，可以考虑替换为 unordered\_map，如果是 vector，可以考虑替换为数组，检查是否有赘余代码，开大空间，可能是部分越界。

各种数据无限对，但是一直 WA，检查一遍初始化。

输出的答案中包括类似 Case，Yes，No 等英文单词以及句子的时候，一定要复制粘贴，自己手打容易出错产生罚时。还要注意看清楚标点符号。
